WHY THIS SERIES

Digital twins, with what already exists

Five articles, five twins, built with System Modeler and Wolfram Language on infrastructure that is already there.

AI makes a good-looking dashboard easy. A reliable twin needs trusted data sources, well-tested functions, and a system model that tells its story in a diagram.

A digital twin is a model of a physical thing, kept in step with data from that thing's sensors.

Crop growth first, because it is slow: a season takes months, so there is no fast communication protocol to solve before the twin exists.

01 — THE CASE

One field, west of Linköping

Winter wheat. Sown in September, harvested the next August. Jordbruksverket's jordbruksskiften — the fields farmers declare each year, with a crop code, in their SAM subsidy application — say what grew; the satellite says how green it was.

02 — THE PROCESS

How a crop grows, and how to watch it from space

The land is ploughed, sown and left. From then on the field is greener or browner — and a satellite sees that every two to three days.

One number turns the picture into something to track. Living leaf absorbs red light and reflects near-infrared; bare soil does neither. The contrast is the NDVI:

Worked once, for the first frame below. Reflectance is the fraction of sunlight the ground sends back in each band, read at the dot: red 0.061, near-infrared 0.103. NDVI = (0.103 − 0.061) / (0.103 + 0.061) = 0.26 — bare soil. On 30 May the same point gives red 0.020 and near-infrared 0.469: the canopy swallows nearly all the red and throws back the infrared, and the ratio is 0.92.

Seven passes over the same field, one per phase, each with its two reflectances and the number they make. The outline is the parcel; the dot is where the bands are read.

03 — THE DRIVERS

What makes it grow

Light
400–700 nm

The part of sunlight a plant can use: PAR. About 3 g of dry matter per MJ the canopy intercepts.

Warmth
Thermal time

Development runs on accumulated degrees above 0 °C, not on days. Flowering at about 1800 °C·d.

Water
A soil bucket

Rain in, evapotranspiration out. Rarely the limit in Sweden — but the model keeps it.

The stages follow the clock: emergence, tillering, a near-standstill over winter, the fast spring growth, flowering, grain fill, harvest.

04 — THE DATA

Reliable sources, one call each

Weather from SMHI — every Swedish station since 1944, open, no key. Greenness from Sentinel-2 through the Planetary Computer.

(* daily Tmax (20) and Tmin (19) from SMHI station 85240, 13 km from the field *)
station = 85240;
url = StringTemplate["https://opendata-download-metobs.smhi.se/api/version/1.0/\
parameter/`p`/station/`s`/period/latest-months/data.csv"];

smhi[p_] := Association @ Cases[
   StringSplit[StringSplit[URLExecute[url[<|"p" -> p, "s" -> station|>], "Text"], "\n"], ";"],
   {_, _, d_ /; StringLength[d] == 10, v_, ___} :> DateObject[d] -> ToExpression[v]];

temperature = Merge[{smhi[20], smhi[19]}, Mean];    (* {14.85, 14.95, 14., 12.7, 9.25} *)
(* Sentinel-2: find the scenes, read the bands at the point — no raster library *)
scenes = URLExecute[HTTPRequest["https://planetarycomputer.microsoft.com/api/stac/v1/search",
   <|Method -> "POST", "ContentType" -> "application/json", "Body" -> ExportString[<|
     "collections" -> {"sentinel-2-l2a"}, "intersects" -> <|"type" -> "Point", "coordinates" -> {15.35, 58.40}|>,
     "datetime" -> "2026-09-01T00:00:00Z/2026-09-24T00:00:00Z"|>, "JSON"]|>], "RawJSON"]["features"];

ndviOf[f_] := Module[{red, nir, scl},
  {red, nir, scl} = URLExecute["https://planetarycomputer.microsoft.com/api/data/v1/item/point/15.35,58.40",
     {"collection" -> "sentinel-2-l2a", "item" -> f["id"], "assets" -> "B04", "assets" -> "B08", "assets" -> "SCL"}, "RawJSON"]["values"];
  If[baseline[f] >= 4., {red, nir} -= 1000];                     (* reflectance offset since Jan 2022 *)
  (nir - red)/(nir + red)]
⚠Three traps. STRÅNG marks missing days with −999 — test for that value, never for the sign (a v > 0 guard deletes every frost day). Subtract 1000 from every band on scenes processed since 2022. At 58°N, distrust any pass with the sun below 25° — low sun reads green that is not there.
05 — THE MODEL

The crop as a system

System dynamics: a stock accumulates, a flow fills or drains it. Soil water, green leaf, dry matter and thermal time are the stocks.

Leaf works the same way: intercepted light becomes sugar, a share becomes new leaf, which intercepts more light — until the canopy catches nearly all of it. After flowering the same stock drains.

07 — THE CLOUD

Keeping the numbers where a browser can reach them

The simulation needs System Modeler, so it runs on one computer once a day. The result goes to a public Wolfram Databin.

bin = Databin["1Hx0aW5gf"];
today = <|"date" -> DateString[Today, "ISODate"], "modelNdvi" -> sim["bus.ndvi"][22*86400.],
   "satellite" -> Last[observations], "forecast" -> Table[sim["bus.ndvi"][d*86400.], {d, 0, 379, 4}]|>;
DatabinAdd[bin, <|"kind" -> "today", "json" -> ExportString[today, "JSON"]|>]

(* read it back — in Wolfram Language, or from any browser *)
ImportString[Last[Normal[bin]]["json"], "RawJSON"]
URLExecute["https://datadrop.wolframcloud.com/api/v1.0/Recent?bin=1Hx0aW5gf", "Text"]
ℹThe public endpoint returns Wolfram syntax and the five newest entries only — so each entry carries its whole payload as one JSON string, and the daily entry is written last.
